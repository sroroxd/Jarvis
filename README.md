# Jarvis

Persönlicher Android-Assistent für das Galaxy S24 Ultra – mit Claude als Gehirn.

## Herunterladen

**Immer die neueste Version:** https://github.com/sroroxd/Jarvis/releases/latest/download/Jarvis.apk

Jede Änderung am Code baut automatisch eine neue APK. Sie lässt sich direkt über die alte installieren.

## Einrichten

1. APK auf dem Handy öffnen und installieren („Aus dieser Quelle erlauben“ bestätigen).
2. Jarvis öffnen, Anthropic-API-Schlüssel eintragen (console.anthropic.com → API Keys).
3. **Jarvis starten** → Mikrofon, Mitteilungen und „Über anderen Apps anzeigen“ erlauben.
4. Bei der Bildschirmfreigabe **Gesamter Bildschirm** wählen.
5. Optional: Seitentaste → Zweimal drücken → App öffnen → **Jarvis sprechen**.

## Bedienung

| J-Farbe | Bedeutung |
|---|---|
| Blau | bereit |
| Rot | hört zu |
| Orange | denkt nach |
| Grün | spricht |

- Antippen: sprechen (während Jarvis redet: unterbrechen und neu fragen)
- Lange drücken: neues Gespräch
- Ziehen: verschieben
- Antwortfeld antippen: Antwort schließen
